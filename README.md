For crowdfunding platforms that rely on real-time transactions and high availability, Denial of Service attacks (DoS/DDoS) often have a direct impact on user trust and capital flow. The file attack_launcher.py evaluates the platform's resilience at different network levels using four common techniques. Written in Python, it makes extensive use of the Scapy and requests packages to build raw packets and application-layer requests, quickly reproducing large volumes of malicious traffic in an experimental environment to help development and defence teams quantify the point of resource exhaustion.

The DDoS detector centred around the script ML_Detector.py, is designed to identify four types of flooding-based DDoS attacks—HTTP, ICMP, SYN, and UDP—on a crowdfunding platform in real time.
